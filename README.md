# ソロエル・クエスト 〜くらべの国の冒険〜

小学5年 算数「単位量あたりの大きさ・速さ・割合」を、公式に数を当てはめるのではなく、
**二本の数直線（ふたつ線のつえ）を自分で動かして比べる**ことで学ぶ家庭学習用RPGです。

## あそぶ

**▶ https://edupower07.github.io/soroeru-quest/**

`index.html` をブラウザで開くだけでも遊べます。1ファイル・外部ライブラリなし・通信なし（オフライン動作）。
iPad・Chromebook・スマホのタッチ操作が最優先です。

## 学習のしくみ

1ミッションは「みきわめる → そろえる → もどす → つたえる」の4ステップ。
出た数を場面の意味に戻す「もどす」を通らないとクリアにならない設計で、
くもわ・みはじのような公式の当てはめに頼らず、量の関係を読む力を育てます。

- 序章〜第5章＋終章（単位量あたりの大きさ／活用／速さ／割合／百分率・歩合）
- 問題の自動生成、わざ図鑑、がくしゅうのきろく、関係図ボード
- どのステップでも問題文と場面の絵を見なおせる「もんだい」カード
- 7つの場所が道でつながった冒険の地図（いま いる 場所が わかる）
- 進み具合は端末内（localStorage）に保存。名前以外の個人情報は扱いません
- 時間制限・ランキング・ゲームオーバーはありません
